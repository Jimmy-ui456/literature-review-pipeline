# 发布准备说明

## 定位
这是早期实验工具，提供可追溯的文献处理流程及工程报告预检。软件版本号不代表经过跨课题专家评测，也不代表科学批准。

## 已有功能
- 课题配置、检索、规范化及去重。
- 书目身份核查、PDF 身份检查、证据卡及人工审阅门禁。
- 审计、CSV/XLSX、RIS 和审阅材料输出。
- 独立工程主题计划、Crossref 候选及 Word 报告预检。
- Zotero 动态引文计划、Word 域转换、插件刷新调用与数字对应核验，见 [操作说明](ZOTERO_DYNAMIC_CITATIONS.md)。
- 隔离真实网络与研究资料的合成演示，以及 Windows/Linux 安装包验证工作流。

## 已知边界
- 尚无专家标注的跨课题金标准，不能宣称可靠召回率或准确率。
- 默认离线测试不能证明所有外部数据服务持续可用；限流、认证、接口变化和网络环境仍需实测。
- 独立工具支持 PDF/HTML 表格结构和可选 OCR，原文位置与待核对状态被保留；复杂扫描表格语义、补充材料对齐及跨段条件归属仍需人工复核。安装及执行边界见 [工程工具说明](ENGINEERING_TOOLS.md)。
- 核心是命令行工具，尚无面向普通用户的图形界面。
- 第三方论文和元数据的使用条件由其来源决定，软件许可证不授予这些内容的再分发权。
- 合成示例不是实际实验。人工审阅仍然必要。

## 首次公开门槛
1. 发布清单、敏感信息检查、wheel/sdist 构建和安装后测试通过。
2. 远端 Windows/Linux、Python 3.10/3.14 自动验证通过。
3. 仓库历史、已上传附件和日志范围检查完成。

达到这些门槛后，可以作为早期版本公开；不以“完善综述系统”或“自动可靠科研结论生成器”宣传。
