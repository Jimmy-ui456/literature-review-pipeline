# 2026-10-19 对抗性审查

本次审查覆盖检索与文档解析工具、Zotero 动态引文、Word 插件调用及源码与安装包发布流程。通过故意构造异常输入和引用错配，先复现失败，再修复并加入回归检查。此记录描述可复现的工程验证，不代表所有环境均无缺陷，也不替代文献内容的科学审阅。

## 发现与修复

| 缺陷或风险 | 修复后行为 |
| --- | --- |
| DOI 与无法识别的作者年份引用混在同一括号中，转换可能漏引 | 对整组逐项校验；无法完整识别时拒绝转换，不吞掉剩余引用 |
| 不合法数字范围、缺失映射、变更过的计划或 Zotero 条目绑定可能进入转换 | 重新扫描原稿并比较内容摘要、完整引用清单和绑定关系；歧义必须先解决 |
| 多 run 拆分的现有域代码可能绕过检查 | 合并域代码识别；检查附属文档部件，拒绝不支持的转换位置 |
| 错误文末 DOI、一个 DOI 对应多个编号、多个 DOI 共用 URI 可能被误判有效 | 检查 DOI、URI、数字编号的双向一致性；按集合校验 CSL 排序后的组合引文 |
| 尚未刷新或缺少可核对的文末 DOI，也可能被描述为完整对应 | 分别报告结构有效、待刷新和数字对应已核实；不把结构检查当作插件成功 |
| 畸形 XML/JSON、损坏 ZIP、输出后缀错误或写入中断可能留下不完整结果 | 严格解析并在发布输出前验证；临时文件写完后原子发布，拒绝覆盖已有文件 |
| Word 在验证前保存；异步插件调用被误当作已完成 | 保存前读取当前 Word XML 并验证，保留独立备份；调用与保存后校验分别记录 |
| 本地 API 根路径返回 HTML，导致健康检查错误 | 使用可返回 JSON 的 itemTypes 端点；Zotero 不可达时在宏调用前停止 |
| 包根命令未实际分派到动态引文模块 | 增加真实命令分派与回归检查 |
| CI 未安装引文可选依赖，相关检查可能被跳过 | 安装 citations extra，验证 lxml、模块入口与安装后行为 |
| Windows 短文件名、路径联接检查及极小时间预算存在平台差异 | 先检查重解析点，再规范化比较路径；拒绝低于系统时钟分辨率的预算 |
| 本地临时研究文件可能影响发布选取 | 显式排除临时目录，保留发布白名单和未知目录拒绝机制 |

## 验证方式

- 对源码运行完整 unittest 测试集，覆盖异常输入、引用错配、文件保护、解析与检索边界。
- 从发布白名单构建源码 ZIP、wheel 和 sdist，检查路径、敏感信息模式及包内容。
- 在全新虚拟环境安装 wheel 及声明的可选依赖，从工作区以外导入安装包，重跑测试、命令入口与两套合成演示。
- 在本机真实 Microsoft Word 与 Zotero 中使用临时文档副本执行插件刷新与保存后校验：43 组动态引文、23 条参考文献；将原第 23 条引用移到前面后，自动变为第 1 条，数字与文末 DOI 对应通过。确认原始文档摘要未改变。
- GitHub 工作流针对 Windows/Linux、Python 3.10/3.14 验证安装包；具体提交是否通过，以对应提交的 Actions 结果为准。

## 使用边界

动态引文需要 Zotero Desktop、可达的本地 API，以及 Windows Word 中已安装的 Zotero 插件；打包工具本身不会替代这些软件。自动转换针对受支持的正文引用语法，复杂脚注、尾注、文本框或已有引用域应先检查处理。数字对应的完整自动核验要求可取得文末条目的 DOI；没有 DOI 的格式只报告能证明的结构和部分映射。异步插件操作、外部服务可用性以及文献元数据和论述是否正确，仍须分别核对。详见 [动态引文操作说明](ZOTERO_DYNAMIC_CITATIONS.md)。

公开代码和测试只使用合成数据；真实稿件、文献库快照、Word 备份和本机测试日志不纳入发布包。
